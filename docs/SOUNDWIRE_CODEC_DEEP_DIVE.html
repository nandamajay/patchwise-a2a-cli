0) What Is SoundWire? (I2C Analogy)

SoundWire is an audio-focused bus (typically one master and one or more audio slaves) used to carry both control messages and time-scheduled audio data between SoC and codecs.

Think of I2C as sending one letter at a time (read/write register transactions), while SoundWire is like a timed metro schedule: every frame has reserved slots, and audio samples keep flowing in those slots continuously.

3) Linux Stack (Who owns what)

ASoC Machine Driver

  • Builds card topology and DAI links.
  • Connects CPU DAI and codec DAI endpoints.
  • Bad link mapping can look like codec failures.

SoundWire Controller Driver

  • Reads controller capabilities.
  • Configures transport/frame params per port.
  • Handles runtime PM, reset, frame-gen checks.

Codec + Codec-SDW Driver

  • Codec core: audio controls, power widgets, MBHC, etc.
  • Codec SDW: slave attach, static port mapping, channel masks.
  • Often waits on initialization_complete during probe.

7) DT Model: Upstream-Safe Thinking

Controller Node

  • Defines bus-level transport properties.
  • Upstream uses qcom,soundwire-vX.Y.Z style compatible.
  • qcom,din-ports/qcom,dout-ports: recognized but deprecated in upstream binding.

Codec Node Under Controller

  • Defines codec slave identity (compatible, reg).
  • Defines static mapping (qcom,tx-port-mapping / qcom,rx-port-mapping).
  • Mapping size must match what codec SDW driver consumes.
// Conceptual upstream form
swrX: soundwire@... {
  compatible = "qcom,soundwire-v1.6.0";

  codec@0,Y {
    compatible = "sdw20217010c00";
    reg = <0 Y>;
    qcom,tx-port-mapping = <1 2>; // example
  };
};

10) Minimal Practical Checklist

  1. Confirm controller node is upstream binding compatible.
  2. Confirm codec mapping values match codec SDW driver expectations.
  3. Remove deprecated forced counts unless strictly required for hardware quirk.
  4. Rebuild DTBs and boot once; capture full dmesg from boot start.
  5. Correlate first mismatch log with first timeout log timestamp.
  6. Only then tune PM/runtime or reset sequence behavior.

Good signal: no mismatch logs + stable frame-gen transitions + codec init completes.
